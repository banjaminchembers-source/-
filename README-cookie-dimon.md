# Cookie Dimon

Маленькая мультяшная печенька, которая живёт поверх других приложений Android.

## Возможности
- Плавающий персонаж поверх любых приложений.
- Перетаскивание пальцем в любое место экрана.
- При касании печенька смеётся, машет рукой и произносит «Ха-ха-ха! Привет!».
- Речь генерируется существующим сервером Димона через /speech и настроенный русский голос OpenAI TTS.
- API-ключ остаётся на сервере и не включается в APK.
- Если сервер недоступен, используется встроенный Android TextToSpeech.
- Постоянное уведомление содержит действие «Убрать».
- После перезагрузки Android персонаж запускается снова, если разрешение на наложение выдано.

## Первый запуск
1. Установить APK.
2. Открыть приложение один раз.
3. Разрешить «Показывать поверх других приложений».
4. Печенька появится поверх рабочего стола и других приложений. Само окно приложения можно закрыть.

## Сборка APK
GitHub Actions workflow Build Cookie Dimon APK собирает release APK при push в cookie-wave-mascot или main. Скачать его можно из раздела Actions, успешный запуск, Artifacts, cookie-dimon-release-apk.
