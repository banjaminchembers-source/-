# Димон — голосовой ИИ-помощник для Android

Flutter-приложение с распознаванием русской речи, голосовыми ответами, простыми командами открытия приложений и подключением к OpenAI через отдельный сервер.

## Что реализовано
- Русское распознавание речи с кнопкой начала/остановки.
- Озвучивание ответов средствами Android TTS.
- Отправка текста в API-сервер и отображение ответа.
- Локальные команды открытия YouTube, Telegram и настроек приложения.
- GitHub Actions для сборки release APK и публикации артефакта.
- Ключ OpenAI хранится на сервере, не в APK.

## Настройка API-сервера и естественного голоса
В репозитории есть `render.yaml` для развёртывания на Render. Откройте [Render](https://render.com), создайте Blueprint из этого GitHub-репозитория и задайте секрет `OPENAI_API_KEY` в настройках сервиса. Ключ вводите только в панели Render — никогда не добавляйте его в GitHub, APK или этот чат. API обслуживает `/chat` (ответы ИИ) и `/speech` (естественная озвучка). Проверка `/health` должна вернуть `{"ok":true}`.

По умолчанию голос — `onyx`, с инструкцией для естественной русской мужской речи. При желании в Render можно поменять `OPENAI_TTS_VOICE` на `echo`, `ash` или `cedar`. Качество/произношение на русском может отличаться между голосами, поэтому стоит попробовать несколько.

## Сборка APK
После push в `main` откройте вкладку **Actions**, выберите **Build Android APK** и скачайте артефакт `dimon-assistant-release-apk` из успешного запуска. В текущем коде базовый адрес сервера задан как `https://dimon-assistant-api.onrender.com`, поэтому отдельный GitHub Secret `APP_API_BASE_URL` не нужен, если Render создаст сервис с этим именем.

## Локальная сборка
```bash
flutter pub get
flutter build apk --release
```

Для подключения API: `flutter build apk --release --dart-define=APP_API_BASE_URL=https://your-api.example.com`.

## Важно
Распознавание речи зависит от доступного на устройстве сервиса распознавания и разрешения микрофона. Голос зависит от Android TTS. Перед публичным запуском API добавьте аутентификацию и ограничения, чтобы посторонние не расходовали бюджет API.
